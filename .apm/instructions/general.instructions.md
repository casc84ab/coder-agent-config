# General Development Instructions

## Principles
- Analyze the repository before acting.
- Respect the architecture and existing conventions.
- Prefer small, focused changes.
- Do not invent requirements or dependencies.
- Do not include secrets in code or files.

## Workflow
- Verify repository state before making changes.
- Run relevant tests when the environment allows.
- Do not claim a test passed unless it was actually run.
- Report executed commands and actual results.
